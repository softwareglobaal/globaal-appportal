# Lessen voor elke volgende agent (overleg 25, 01-11-2026)

Uit De Prijsonderzoeker: na een dag en tien Codex-rondes had de agent nog geen enkele vraag gedaan, omdat een grendel op
een onbewezen uitleg (`overageStatus: "allowed"`) alles blokkeerde. Overleg 25, X4 en K4 (3-0):

1. Doe eerst een echte, kleine proefvraag met een harde grens, en kijk wat er gebeurt. Bouw pas daarna grendels.
2. Een grendel mag alleen stoppen op een signaal dat gemeten en begrepen is. Een veld waarvan de betekenis onbekend is,
   wordt gelogd en blokkeert niet.
3. Toets elke nieuwe grendel aan de vraag: kan de agent daarna nog draaien? Een controleronde mag de agent niet verder
   lamleggen.
4. De eerste versie is zo klein dat ze een dag later al antwoord geeft.
5. Leg elke harde eis van Mehdi vast in een eindtest (hier: werkt, en kost geen geld).
